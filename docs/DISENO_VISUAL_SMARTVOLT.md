# Diseño visual — SmartVolt Asistencia

## Objetivo

Facilitar el registro y la consulta de asistencia en faena a personas que necesitan una interfaz directa, legible y predecible, incluso si no están familiarizadas con aplicaciones móviles.

## Criterios visuales

- **Azul marino y azul:** transmiten confianza, orden y orientación. Se utilizan en la identidad, títulos, navegación y acciones principales.
- **Verde:** comunica una condición correcta o una acción confirmada, como una presencia lista o una entrada registrada.
- **Ámbar:** identifica situaciones que requieren atención, como atrasos o verificaciones pendientes.
- **Rojo:** se reserva para errores, rechazos e incidencias relevantes.
- **Fondos claros y tarjetas blancas:** separan grupos de información y mejoran la lectura en pantallas de uso cotidiano.
- **Tipografía sans serif y tamaños ampliados:** priorizan la lectura rápida y reducen la dependencia de textos pequeños.
- **Botones amplios y textos explícitos:** hacen más fácil reconocer la acción disponible; se evita depender solo de iconos.
- **Estados con texto y color:** el significado no depende exclusivamente del color.

## Material Design 3

La interfaz utiliza los roles de color, tipografía, formas, botones, campos y tarjetas de Material 3 mediante `MaterialTheme`. Se mantiene una apariencia clara y consistente entre dispositivos para la demostración académica.

## Alcance de este ajuste

Este cambio es de presentación. Se mantienen los flujos existentes de navegación, validación, estado, persistencia local y acceso a recursos nativos. No se agregan opciones visuales que no tengan una acción implementada.

Las pantallas de mockup que muestran administración completa de nómina, configuración de turnos, alertas avanzadas o exportación representan una propuesta UX/UI más amplia; no deben interpretarse como funciones agregadas por este rediseño si no existen en el MVP actual.
