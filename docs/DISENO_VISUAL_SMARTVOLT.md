# Diseño visual de SmartVolt Asistencia

## Objetivo

Que registrar y consultar la asistencia en faena sea directo, legible y predecible, incluso para quien no está acostumbrado a usar aplicaciones móviles.

## Criterios visuales

El azul marino y el azul transmiten confianza, orden y orientación. Se usan en la identidad, los títulos, la navegación y las acciones principales.

El verde indica una condición correcta o una acción ya confirmada, como una presencia lista o una entrada registrada. El ámbar señala lo que requiere atención, como atrasos o verificaciones pendientes. El rojo queda reservado para errores, rechazos e incidencias.

Los fondos claros y las tarjetas blancas separan grupos de información y mejoran la lectura en pantallas de uso diario. La tipografía sans serif, con tamaños ampliados, prioriza la lectura rápida y reduce la dependencia de textos pequeños. Los botones son amplios y llevan texto explícito, de modo que la acción no dependa solo de un icono. Los estados combinan texto y color, así que el significado no se pierde si no se distingue el color.

## Material Design 3

La interfaz utiliza los roles de color, tipografía, formas, botones, campos y tarjetas de Material 3 a través de `MaterialTheme`. La apariencia clara se mantiene igual entre dispositivos para la demostración académica.

## Alcance de este ajuste

El cambio es de presentación. Los flujos de navegación, validación, estado, persistencia local y acceso a recursos nativos siguen igual. No se agregaron opciones visuales sin una acción implementada detrás.

Las pantallas de ejemplo con administración de nómina, configuración de turnos, alertas avanzadas o exportación son una propuesta de diseño más amplia. El MVP no incluye esas funciones.
