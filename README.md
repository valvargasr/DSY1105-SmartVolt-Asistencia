# SmartVolt Asistencia

## Asignatura
DSY1105 - Desarrollo de Aplicaciones Móviles

## Descripción
Aplicación móvil de demostración para apoyar el
registro de entrada y salida de trabajadores
en faenas de construcción.

## Objetivo
Proponer una solución que permita registrar
asistencias y consultar su estado, considerando
la validación de ubicación y proximidad física,
el almacenamiento local y el funcionamiento
ante problemas de conectividad.

## Funcionalidades planificadas
- Registro de entrada y salida.
- Formularios con validaciones.
- Panel de estado para supervisión.
- Historial de marcas guardadas localmente.
- Integración de recursos nativos del dispositivo.
- Interfaz Material 3 y navegación.
- Animaciones y mensajes de retroalimentación.

## Tecnologías por confirmar
- Kotlin
- Android Studio
- Jetpack Compose
- Material Design 3
- Arquitectura MVVM
- Room / SQLite
- GPS y Bluetooth BLE
